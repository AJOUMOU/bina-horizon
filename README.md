# Bina Horizon Association

Official site for **Bina Horizon Association** — *Talented for Impact.*  
A faith-inspired movement empowering girls and young African women to rise beyond boundaries through education, mentorship, creative trades, enterprise, and spiritual grounding.

Founder & visionary leader: **Wandia Remedy**.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:4327](http://localhost:4327) if you start the server with `npm run dev -- --port 4327 -H 0.0.0.0`, or the port printed in the terminal.

## Pages

- `/` — Index (editorial home)
- `/about` — The Name, vision, founder, governance
- `/programs` — Objectives and six program pillars
- `/values` — The Five R’s
- `/join` — Letter of intent (stored locally in this preview)
